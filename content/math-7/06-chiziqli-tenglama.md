ax = b ko'rinishidagi tenglama bir noma'lumli chiziqli tenglama deyiladi. Bu yerda x noma'lum, a va b esa berilgan sonlar. Tenglamaning ildizi deb noma'lumning tenglamani to'g'ri sonli tenglikka aylantiradigan qiymatiga aytiladi.

Tenglamalarni yechishda ikki xossadan foydalaniladi:
- Tenglamaning istalgan hadini qarama-qarshi ishora bilan bir tomondan ikkinchi tomonga o'tkazish mumkin.
- Tenglamaning ikkala tomonini noldan farqli bir xil songa ko'paytirish yoki bo'lish mumkin.

### 1-misol
3x - 7 = 11 tenglamani yeching.
Yechish: -7 ni o'ng tomonga +7 qilib o'tkazamiz: 3x = 11 + 7, ya'ni 3x = 18. Ikkala tomonni 3 ga bo'lamiz: x = 6.
Tekshirish: 3 · 6 - 7 = 18 - 7 = 11. Tenglik to'g'ri.

### 2-misol
5x + 4 = 2x - 8 tenglamani yeching.
Yechish: noma'lumli hadlarni chap tomonga, sonlarni o'ng tomonga yig'amiz: 5x - 2x = -8 - 4, 3x = -12, x = -4.

<!-- page: 52 -->
Qavsli tenglamada avval qavslar ochiladi. Masalan, 2(x - 3) = x + 5. Qavsni ochamiz: 2x - 6 = x + 5. Keyin 2x - x = 5 + 6, demak x = 11.

ax = b tenglamaning nechta ildizi borligi a va b ga bog'liq:
- a noldan farqli bo'lsa, tenglama yagona ildizga ega: x = b / a.
- a = 0 va b noldan farqli bo'lsa, tenglama ildizga ega emas. Masalan, 0 · x = 5.
- a = 0 va b = 0 bo'lsa, istalgan son tenglamaning ildizi bo'ladi: 0 · x = 0.

Ko'p uchraydigan xato: hadni boshqa tomonga o'tkazganda ishorasini o'zgartirmaslik. Masalan, 3x - 7 = 11 dan 3x = 11 - 7 deb yozish noto'g'ri.

### 3-misol
Bir son ikkinchisidan 5 ga katta, ularning yig'indisi 27 ga teng. Bu sonlarni toping.
Yechish: kichik sonni x deb olsak, katta son x + 5 bo'ladi. x + (x + 5) = 27, 2x + 5 = 27, 2x = 22, x = 11. Sonlar: 11 va 16.

## Asosiy g'oyalar
- Chiziqli tenglama ax = b ko'rinishida bo'ladi; ildiz tenglamani to'g'ri tenglikka aylantiradi.
- Hadni boshqa tomonga o'tkazganda uning ishorasi qarama-qarshisiga o'zgaradi.
- Tenglamaning ikkala tomonini noldan farqli bir xil songa bo'lish mumkin.
- a noldan farqli bo'lsa, yagona ildiz x = b / a; a = 0 bo'lsa, ildiz yo'q yoki cheksiz ko'p.
- Topilgan ildizni tenglamaga qo'yib tekshirish kerak.
