Ikki ifoda yig'indisining kvadrati: (a + b)^2 = a^2 + 2ab + b^2. Ya'ni birinchi ifodaning kvadrati, plyus ikkala ifoda ko'paytmasining ikkilangani, plyus ikkinchi ifodaning kvadrati.

Bu formula ko'phadni ko'phadga ko'paytirishdan kelib chiqadi: (a + b)^2 = (a + b)(a + b) = a^2 + ab + ab + b^2 = a^2 + 2ab + b^2.

Ikki ifoda ayirmasining kvadrati: (a - b)^2 = a^2 - 2ab + b^2. Bu yerda faqat o'rta hadning ishorasi minus bo'ladi, b^2 esa har doim plyus ishora bilan yoziladi.

### 1-misol
(x + 3)^2 = x^2 + 2 · x · 3 + 3^2 = x^2 + 6x + 9.

### 2-misol
(2m - 5)^2 = (2m)^2 - 2 · 2m · 5 + 5^2 = 4m^2 - 20m + 25.

<!-- page: 32 -->
Eng ko'p uchraydigan xato: (a + b)^2 ni a^2 + b^2 deb yozish. Bu noto'g'ri, chunki o'rta had 2ab tushib qoladi. Tekshirib ko'ring: a = 1 va b = 2 bo'lsa, (1 + 2)^2 = 9, lekin 1^2 + 2^2 = 5.

Formulalar hisoblashni osonlashtiradi. Masalan, 51^2 = (50 + 1)^2 = 2500 + 100 + 1 = 2601 va 99^2 = (100 - 1)^2 = 10000 - 200 + 1 = 9801.

Formulani teskari tomonga ham qo'llash mumkin: a^2 + 2ab + b^2 ko'rinishidagi uchhadni (a + b)^2 ko'rinishida yozish mumkin. Masalan, x^2 + 10x + 25 = x^2 + 2 · x · 5 + 5^2 = (x + 5)^2. Bunday uchhad to'la kvadrat deyiladi.

## Asosiy g'oyalar
- (a + b)^2 = a^2 + 2ab + b^2.
- (a - b)^2 = a^2 - 2ab + b^2; faqat o'rta had manfiy bo'ladi.
- (a + b)^2 ifoda a^2 + b^2 ga teng emas: o'rta had 2ab ni unutmaslik kerak.
- Formulalar sonlarni og'zaki kvadratga ko'tarishga yordam beradi.
- To'la kvadrat uchhadni (a + b)^2 yoki (a - b)^2 ko'rinishida yozish mumkin.
